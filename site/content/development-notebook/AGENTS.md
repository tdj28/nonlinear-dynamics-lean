# Development Notebook authoring scope

Read the repository-root `BLOG-AGENTS.md` completely before adding or changing
an entry in this directory.

Apply that guide with these path and naming mappings:

- `Research Note` maps to `Development Notebook entry`.
- `blog-source/content/posts/**` maps to `site/content/development-notebook/**`.
- `blog-source/content/knowledge-base/**` maps to `site/content/knowledge-base/**`.
- Site-specific Praxagent names, links, examples, and branding are illustrative
  only. Do not copy them into this project.

The guide's integrity, disclosure, citation, accessibility, provenance, review,
and human-publication gates remain binding. New entries start with `draft: true`
and `pro_reviewed: false`.
